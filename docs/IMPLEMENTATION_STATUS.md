# Текущий статус реализации компонентов Sentinel-RS (Implementation Status)

Данный документ фиксирует актуальный статус реализации компонентов системы по результатам выполнения дорожной карты задач (TASKS_ROADMAP).

| Компонент / Возможность | Статус реализации | Статус тестирования | Примечания |
| :--- | :--- | :--- | :--- |
| **Process Monitoring (exec/fork/exit)** | Implemented | Tested | Мониторинг через eBPF tracepoints, C-совместимый ABI `#[repr(C)]`, ring buffer со счетчиками потерь и защитой от DoS. |
| **Process Lineage DAG** | Implemented | Tested | Двухуровневый граф (Process Graph + Data Flow Graph) с composite key `ProcessKey` (pid, tgid, start_time_ns, pid_ns, dev_ino), вторичной индексацией `tgid -> Vec<ProcessKey>` в `LruCache`. Unit-тесты на PID reuse и data flow causation. |
| **PID Reuse Protection** | Implemented | Tested | Использование Linux `pidfd` (`pidfd_open`, `pidfd_send_signal`), верификация идентичности ДО отправки любого сигнала, повторная проверка под `SIGSTOP`. Fallback для ядер < 5.3 без отправки сигналов при расхождении start_time. Тест SEC-001. |
| **Taint Tracking (Файлы секретов)** | Implemented | Tested | Пятиуровневый `TaintLevel` (None, Observed, SensitiveAccess, SuspectedPropagation, ConfirmedPropagation), фиксация `SensitiveSource` (SshKeys, ShadowFile, CloudCredentials, ApiTokens, GpgKeys) и `TaintRecord`. |
| **IPC Data Flow Propagation** | Implemented | Tested | Поддержка передачи дескрипторов через Unix-сокеты (`SCM_RIGHTS`), анонимных и именованных каналов (pipe/FIFO), граф потоков данных `DataFlowEdge` с трассировкой причинно-следственных связей. |
| **Network Interception & NFQUEUE** | Implemented | Tested | Перехват через eBPF mark и NFQUEUE реализован с сохранением контекста сокетов. |
| **Network Isolation (nftables)** | Implemented | Tested | Транзакционный `NetworkIsolationManager` с 3 уровнями (Selective, Restricted, FullIsolation). Исключительно атомарные пакетные транзакции в таблице `inet sentinel` (без flush ruleset). Механизм Anti-Lockout с таймером автоотката и подтверждением через `sntctl network confirm-isolation`. |
| **Risk Engine** | Implemented | Tested | Трёхуровневая модель Evidence-Based Risk Engine (`Confidence`, `Impact`, `EvidenceEvaluation`). Категоризация угроз, детерминированные скоры и обоснование решений. |
| **Autonomous Response (Kill/Suspend)** | Implemented | Tested | Двухфазный безопасный terminate/suspend на базе `pidfd`. Политика защиты критических системных процессов (`ProcessProtectionPolicy`), запрет воздействия на системные бинарники (/usr/sbin, /usr/lib/systemd) и авто-понижение до Alert + сокетная изоляция. |
| **Health Monitoring & Watchdog** | Implemented | Tested | Машина состояний `AgentState` (Starting, Healthy, Degraded, ProtectionUnavailable, Recovering, Stopping), `FailurePolicyManager`. Watchdog отправляет `WATCHDOG=1` только при реальном здоровье подсистем; приостанавливает пинг при `ProtectionUnavailable` > 30с; `READY=1` и `STOPPING=1`. |
| **Privilege Separation** | Implemented | Tested | Архитектура разделена на `sentineld-core` и привилегированный хелпер `sentinel-privileged`. Удалены опасные `CAP_SYS_ADMIN` и `CAP_SYS_PTRACE`; оставлены минимальные `CAP_BPF`, `CAP_PERFMON`, `CAP_NET_ADMIN`, `CAP_KILL`, `CAP_DAC_READ_SEARCH`. |
| **Event ABI & RingBuffer Loss Counter**| Implemented | Tested | Стабильный C-совместимый ABI (`#[repr(C)]`) для всех событий eBPF (`RawEbpfHeader`, `RawFileOpenEvent`, и др.), bounds-safe нормализация `EventNormalizer`, счётчики потерь в ring buffer (`RingBufferMetrics`), per-PID rate limiting с bypass для критических событий безопасности. |
| **SQLite Persistent Storage** | Implemented | Tested | Полноценная поддержка WAL режима (`PRAGMA journal_mode = WAL`), контрольные точки `PRAGMA wal_checkpoint(TRUNCATE)`, автоматический фоновый retention task, проверка дисковой квоты (<500MB suppresses raw events). |
| **SO_PEERCRED IPC Server** | Implemented | Tested | Аутентификация UID/GID через `SO_PEERCRED`, ограничение на длину строки 64KB, таймаут чтения 5 секунд, защита от DoS. |
| **Adversarial Test Suite (SEC-001..012)**| Implemented | Tested | Полный набор интеграционных adversarial-тестов SEC-001..SEC-012 (`crates/sentineld/tests/adversarial_sec_suite.rs`), CI/CD бенчмарк SLA (`crates/sentineld/benches/sla_benchmarks.rs`), автоматизированный запуск в live VM окружении (`tests/run_live_vm_tests.sh`). |
